# 吃了没

无广告、界面极简、下单快、配送透明的外卖 App（v1 演示版）。

## 在线预览

<https://Musaen.github.io/chilemei/>

每次推送到 `main` 分支都会自动重新构建并更新线上版本。

## 部署后端（免费云，让线上也能登录）

线上静态版（GitHub Pages）默认运行在演示模式，登录功能需要后端服务。按下面步骤免费部署：

1. 打开 [Render](https://render.com)（可用 GitHub 账号直接授权注册）；
2. 点击 **New → Blueprint**，选择本仓库（会自动读取 `render.yaml`），确认创建 `chilemei-api` Web Service；
3. 等待部署完成，复制服务地址，形如 `https://chilemei-api.onrender.com`；
4. 回到 GitHub 仓库 **Settings → Secrets and variables → Actions → Variables**，新建变量 `API_URL`，值填上一步的地址；
5. 推送任意一次提交（或手动触发一次 GitHub Actions），前端构建时会自动把 API 地址打进线上版本；
6. 打开线上网址，登录页即可使用（手机号 + 验证码 `123456`）。

> 免费版说明：Render 免费实例闲置约 15 分钟会休眠，休眠后首次访问需要约 50 秒冷启动；
> SQLite 数据存在实例临时磁盘，重新部署/休眠重启会清空，适合演示，正式使用建议换托管数据库。

## 运行方式

```bash
npm install
npm --prefix server install
npm run seed        # 首次：把店铺/菜品导入数据库
npm run server      # 启动后端 API（http://localhost:8787）
npm run dev
```

浏览器打开 `http://localhost:5173` 即可体验。桌面浏览器会自动居中显示手机宽度，模拟 App 效果。

**在线模式 / 演示模式**：后端启动时，店铺、订单、收藏、拉黑、忌口等数据走服务端（手机号 + 验证码 123456 登录）；后端不可用时自动回退到内置演示数据，公开网页版（GitHub Pages）即运行在演示模式。

后端 API 测试：`npm run server:test`

## 功能

- 首页：时段智能推荐、「猜你喜欢」、分类筛选、附近好店
- 首页：热搜 + 搜索历史联想、筛选（免配送费/有满减/高分）、营业状态角标
- 店铺：菜单、规格选择、加购、购物车栏、满减活动、评价墙、商家信息卡、拉黑店铺
- 忌口：点餐时可选择「这一顿不想吃什么」，自动隐藏相关菜品并写入订单备注
- 优惠券：领券中心、我的优惠券、结算自动抵扣、取消订单自动返还
- 结算：地址选择、优惠券 + 满减 + 新人立减全明细、满 30 免配送费、餐具偏好
- 支付：微信 / 支付宝模拟支付
- 配送：状态时间轴、模拟地图骑手动画、倒计时、超时必赔、取消订单、催单
- 评价：送达后评价（星级 + 标签 + 文字）、店铺评分聚合
- 订单：历史订单、一键再来一单（含规格还原）
- 我的：昵称、地址管理、收藏店铺、已拉黑店铺管理
