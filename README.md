# 吃了没

无广告、界面极简、下单快、配送透明的外卖 App（v1 演示版）。

## 在线预览

<https://Musaen.github.io/chilemei/>

每次推送到 `main` 分支都会自动重新构建并更新线上版本。

## 运行方式

```bash
npm install
npm --prefix server install
npm run seed        # 首次：把店铺/菜品导入数据库
npm run server      # 启动后端 API（http://localhost:8787）
npm run dev
```

浏览器打开 `http://localhost:5173` 即可体验。桌面浏览器会自动居中显示手机宽度，模拟 App 效果。

**在线模式 / 演示模式**：后端启动时，店铺、订单、收藏、拉黑、忌口等数据走服务端（手机号 + 验证码 123456 登录）；后端不可用时自动回退到内置演示数据，公开网页版（GitHub Pages）即运行在演示模式。

后端 API 测试：`npm run server:test`

## 功能

- 首页：时段智能推荐、「猜你喜欢」、分类筛选、附近好店
- 店铺：菜单、加购、购物车栏、拉黑店铺
- 忌口：点餐时可选择「这一顿不想吃什么」，自动隐藏相关菜品并写入订单备注
- 结算：地址选择、价格透明明细、满 30 免配送费
- 支付：微信 / 支付宝模拟支付
- 配送：状态时间轴、模拟地图骑手动画、倒计时、超时必赔
- 订单：历史订单、一键再来一单
- 我的：昵称、地址管理、收藏店铺、已拉黑店铺管理

## 说明

- 所有数据为北京风格 mock 数据，仅存于浏览器 localStorage，无后端、无真实支付。
